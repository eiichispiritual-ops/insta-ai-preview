# インスタAI 全部入りパック

「スキル」は、AIに渡す手順書のことです。このパックには、その手順書と、リール動画の編集の指示文が入っています。
上から順に、押す・打つ・貼るだけで始められます。動画を見る必要はありません。

## 目次

1. はじめ方（AIごと。ターミナルの人は A・B・C の3つ）
2. AIに聞かれたら、こう返す
3. 中身一覧
4. 動画編集の使い方
5. 詰まったとき3点
6. 置き場所が違うとき

## 1. はじめ方

先に、使うAIを1つ選びます。迷ったら「ChatGPT・Claude のアプリ」で始めてください。あとから切り替えても無駄になりません。ターミナル（文字で Mac に指示を出す画面。打ち間違えても壊れません）を使うのは Claude Code と Codexだけです。この手順は Mac で行います（サイトの「はじめる」と同じ順・同じ言葉です）。
Windows の人は、「ChatGPT・Claude のアプリを使う人」を選んでください。

### Claude Code を使う人

やることは A・B・C の3つです。どれも「コピーして、ターミナルに貼って（command＋V）、Enter」です。

**A. ターミナルを開いて、Claude Code を入れる（初回だけ）**

command＋スペースを押し、「ターミナル」と打って Enter。文字だけの画面が開きます（打ち間違えても壊れません）。すでに Claude Code が入っている人は B へ進みます。
「command not found: claude」や「~/.local/bin is not in your PATH」と出たら、次の1行を貼って Enter し、ターミナルを開き直してから、もう一度貼ります。
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```
```bash
curl -fsSL https://claude.ai/install.sh | bash && claude --version
```
うまくいった印：最後に数字（バージョン）が出ます。

**B. zip を受け取って、手順書を入れる**

サイトの「全部入りzipをダウンロード」を押します（開かなくて大丈夫です）。次の1行をそのまま貼ります。作業フォルダ `~/insta-ai` を作り、zip を開き、手順書を置くところまで自動でやります（「insta-ai-all (1).zip」のような名前や、Safari が先に開いてしまった場合も動きます）。「“ターミナル”が“ダウンロード”フォルダ内のファイルにアクセスしようとしています」と出たら「許可」を押します。
```bash
mkdir -p ~/insta-ai && cd ~/insta-ai && Z=$(ls -t ~/Downloads | grep "^insta-ai-all.*\.zip$" | head -1); D=$(ls -t ~/Downloads | grep "^insta-ai-all" | grep -v "\.zip$" | head -1); if [ -n "$Z" ]; then unzip -oq ~/Downloads/"$Z" -d insta-ai-all; elif [ -n "$D" ]; then rm -rf insta-ai-all && cp -R ~/Downloads/"$D" insta-ai-all; fi; if [ -d insta-ai-all/insta-ai-create ]; then mkdir -p .claude/skills && cp -R insta-ai-all/insta-ai-create .claude/skills/ && ls .claude/skills; else echo "zip が見つかりません。ダウンロードし直してください"; fi
```
うまくいった印：最後に `insta-ai-create` と出ます。「zip が見つかりません」と出たら、zip をダウンロードし直して、同じ1行を貼り直します。

**C. 起動して、ログインして、最初の1行を貼る**
```bash
cd ~/insta-ai && claude
```
初回は案内に沿ってログインします。「Do you trust the files in this folder?」と出たら Enter（Yes）。起動したら、次の1行を貼ります。
```
インスタAIのスキル（/insta-ai-create）で、私のプロフィールの、表示名と紹介文を作って。質問せず、足りないところは要確認と書いて仮置きで、そのまま案まで出して。
```
出てくるもの：この1行はプロフィール用なので、表示名と紹介文の案と、選んだ理由が出ます。台本（日付とタイトル・台本の本文・撮影メモ）、フィード投稿（ページごとの見出し・本文・配置）、ストーリー（1枚ごとの本文・使う素材）を作る人は、サイトの「はじめる」で作りたいものを選ぶと、言葉と「出てくるもの」が切り替わります。AIが「要確認」と書いた所は、あなたの本当のことに書き換える場所です。
次の日に続きをやるときは、ターミナルを開いて C の1行目だけを貼れば始められます。

### Codex を使う人

やることは A・B・C の3つです。どれも「コピーして、ターミナルに貼って（command＋V）、Enter」です。

**A. ターミナルを開いて、Codex を入れる（初回だけ）**

command＋スペースを押し、「ターミナル」と打って Enter。文字だけの画面が開きます（打ち間違えても壊れません）。すでに Codex が入っている人は B へ進みます。
Codex には Node.js が要ります。先に `node -v` と打ち、数字が出なければ https://nodejs.org から LTS を入れて、ターミナルを開き直します。「EACCES」「permission denied」と出たら、`sudo npm install -g @openai/codex` を貼り、Mac のパスワード（画面には出ません）を打ちます。
```bash
npm install -g @openai/codex && codex --version
```
うまくいった印：最後に数字（バージョン）が出ます。

### ChatGPT・Claude のアプリを使う人

**① 手順書をコピーする**（サイトの「はじめる」で「ChatGPT・Claudeのアプリ」を選び、手順3で作りたいものを選んでから、「手順書をコピー」ボタンを押します。迷ったら「手順書を全部コピー」でも使えますが、長いので入力欄に入らないことがあります）

**② AIを開く**（新しい会話を始めます）

**③ 貼る**
1. 入力欄に貼って送ります。長いので、AIの返事が出るまで待ちます。
2. 返事が出たら、次の1行を貼って送ります。
```
いま貼った手順書を使って、私のプロフィールの、表示名と紹介文を作って。質問せず、足りないところは要確認と書いて仮置きで、そのまま案まで出して。
```
出てくるもの：この1行はプロフィール用なので、表示名と紹介文の案と、選んだ理由が出ます。台本（日付とタイトル・台本の本文・撮影メモ）、フィード投稿（ページごとの見出し・本文・配置）、ストーリー（1枚ごとの本文・使う素材）を作る人は、サイトの「はじめる」で作りたいものを選ぶと、言葉と「出てくるもの」が切り替わります。AIが「要確認」と書いた所は、あなたの本当のことに書き換える場所です。

サイトを開けない人は、zip の中の `全部入り_アプリ用.md` を開いて全文をコピーし、①のかわりに使います（ボタンと同じ内容です）。`SKILL.md` だけを貼ると、AIが読めない参照資料が出るので、使わないでください。

## 2. AIに聞かれたら、こう返す

質問が来たときの返し方です。3点まとめて来ることもあります。まとめて返してOKです。そのままコピーして、（ ）や〇〇のところだけ書き換えて送ります。

**3点まとめて返す**
```
ジャンルは〇〇です。見る人は、（どんな場面で何に）困っている人です。使える素材は、スマホで撮れる手元の動画と写真です。ないものは作らないでください。私が実際に試したことは（ここに書く）です。ない場合は、見る人への呼びかけで作ってください。
```

**聞かれたこと：ジャンル・見る人・経験（どんな人に、何を届けたいか）**
```
ジャンルは〇〇です。見る人は、（どんな場面で何に）困っている人です。私が実際に試したことは（ここに書く）です。ない場合は、見る人への呼びかけで作ってください。
```

**聞かれたこと：何を作りたいか・どこまで決まっているか**
```
まだ何も決まっていません。まず、いちばん簡単なものから1つ一緒に作ってください。
```

**聞かれたこと：実績・画像・動画など、私が持っていないもの**
```
それは持っていません。ないものは作らず、今ある材料だけでできる形にしてください。
```

## 3. 中身一覧

```
README.md
全部入り_アプリ用.md   アプリに貼る連結済みの1ファイル（サイトの「手順書を全部コピー」と同じ内容。スキルのフォルダの外に置いてあります）
insta-ai-create/        手順書の本体（SKILL.md と references/ の36本、合計37ファイル）。これだけを cp -R します
video-edit/            （動画編集用）
  howto_<形式>.md       形式ごとの作り方（6形式：アフレコ・VLOG・トーク・抽象マーケ・ランキング・比較）
  prompt_<形式>.md      AIに貼る指示文（6本）
  examples.md           作例の題名・形式・こんな人に
  howto_mystyle.md      自分の動画の型を作る（外注している編集の再現）の作り方
  prompt_mystyle.md     その指示文（①測って型の初版 ②再現して比べる ③型を直す（くり返す） ④仕上げ ⑤新しい素材 ⑥次回の一言）
```

- `video-edit/prompt_voiceover.md`：顔を出さず、あとから録った自分の声で、生活映像を合わせて作りたい人。
- `video-edit/prompt_vlog.md`：朝から外出までなど、日常を撮って説明につなげたい人。
- `video-edit/prompt_talk.md`：自分が話す映像があり、実績などを部品として差し込みたい人。
- `video-edit/prompt_abstract.md`：身近な題材を入口に、人が反応する理由を解説し、権威性や実績を部品として差し込みたい人。
- `video-edit/prompt_ranking.md`：紹介したいもの（ツール・商品・方法）が複数あり、順位をつけて見せたい人。
- `video-edit/prompt_comparison.md`：2つの考え方や2人を並べて、違いを見せたい人。

## 4. 動画編集の使い方

編集ソフトは使いません。AIが動画を組み立てます。動画の書き出しまでできるのは Mac の Claude Code か Codex です（Windows・スマホの人は、アプリで編集指示書の表まで作り、CapCut などで並べます）。Claude Code か Codex を、素材を置いたフォルダで開いて使います。

1. `video-edit/examples.md` の「こんな人に」を読んで、形式を1つ選びます。
2. `video-edit/howto_<形式>.md` の「用意するもの」を見て、素材を1つのフォルダに集めます。
3. `video-edit/prompt_<形式>.md` を開き、全文をコピーして、AIに貼ります。
4. 素材の名前や、出したい場面を聞かれたら、上の「こう返す」を使って答えます。
5. 出てくるもの：編集指示書（何秒に何を出すかの表）と、動画を書き出す手順です。手順どおりに実行すると、mp4 ができます。

## 4-2. 自分の動画の型を作る（外注している編集を AI で再現）

すでに同じ作り方で投稿している人は、`video-edit/howto_mystyle.md` を読み、`video-edit/prompt_mystyle.md` の①から順に Claude Code か Codex に貼ります。見本1本を測って型を作り、同じ素材から再現して見本との差を埋めるのをくり返して型を磨きます。仕上がったら、次からは一言で同じ作りの動画を書き出せます。

## 5. 詰まったとき3点

1. **貼ったのに動かない**：置き場所が違う場合が多いです。Claude Code は `.claude/skills/insta-ai-create/SKILL.md`、Codex は `~/.agents/skills/insta-ai-create/SKILL.md`（古い版の Codex は `~/.codex/skills/insta-ai-create/SKILL.md`）があるか、作業フォルダ（`~/insta-ai`）の中で、次で確認します。
```bash
ls .claude/skills/insta-ai-create/SKILL.md ~/.agents/skills/insta-ai-create/SKILL.md
```
2. **アプリで手順書として動かない**：ファイルの添付と、手順書としての登録は別です。サイトの「手順書を全部コピー」ボタン（または `全部入り_アプリ用.md` の全文）を、入力欄に貼って始めてください。
3. **動画編集で動画ツールが見つからない**：次を打って、エラーになったら、AIに「このパソコンに ffmpeg を入れる手順を教えて」と聞きます。
```bash
ffmpeg -version
```

## 6. 置き場所が違うとき

お使いの版で場所が違う場合は、Claude Code・Codex それぞれのドキュメントの skills の項を見てください。

それでも「insta-ai-create のスキルで」が効かないときは、アプリを使う人と同じ方法に切り替えます。サイトの「手順書を全部コピー」ボタン（または `全部入り_アプリ用.md` の全文）を、AIの入力欄に貼って送ってから、最初の1行を「いま貼った手順書を使って、」で始めて送ります。
