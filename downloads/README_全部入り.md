# インスタAI 全部入りパック

「スキル」は、AIに渡す手順書のことです。このパックには、その手順書と、リール動画の編集の指示文が入っています。
上から順に、押す・打つ・貼るだけで始められます。動画を見る必要はありません。

## 1. 3ステップ

先に、使うAIを1つ選びます。zip は、すでにダウンロード済みの前提です。

### Claude Code を使う人

**① zip を解凍して置く**（ダウンロードしたフォルダで、次の3行を貼って実行）
```bash
unzip insta-ai-all.zip -d insta-ai-all
mkdir -p .claude/skills
cp -R insta-ai-all/insta-ai-create .claude/skills/
```
**② AIを開く**
```bash
claude
```
**③ この1行を貼る**
```
インスタAIのスキルで、私のプロフィールを作って。分からないことは1つずつ質問して
```
出てくるもの：AIが質問してきます。答えると、表示名と紹介文の案が出ます。「/insta-ai-create」と打っても始められます。

### Codex を使う人

**① zip を解凍して置く**
```bash
unzip insta-ai-all.zip -d insta-ai-all
mkdir -p ~/.codex/skills
cp -R insta-ai-all/insta-ai-create ~/.codex/skills/
```
**② AIを開く**
```bash
codex
```
**③ この1行を貼る**
```
insta-ai-create のスキルで、私のプロフィールを作って。分からないことは1つずつ質問して
```
出てくるもの：AIが質問してきます。答えると、表示名と紹介文の案が出ます。

### ChatGPT・Claude のアプリを使う人

**① zip を解凍する**（ダブルクリックで開きます。中の `insta-ai-create/SKILL.md` を使います）

**② AIを開く**（新しい会話を始めます）

**③ 貼る**
1. `SKILL.md` を開いて、全文をコピーし、入力欄に貼って送ります。
2. 次に、この1行を貼って送ります。
```
上の手順書に従って、私のプロフィールを作って。分からないことは1つずつ質問して
```
出てくるもの：AIが質問してきます。答えると、表示名と紹介文の案が出ます。

## 2. AIに聞かれたら、こう返す

そのままコピーして、〇〇のところだけ書き換えて送ります。

**聞かれたこと：ジャンル・読者・経験（どんな人に、何を届けたいか）**
```
ジャンルは〇〇です。読者は、〇〇で困っている人です。私が実際に試したことは〇〇です。
```

**聞かれたこと：何を作りたいか・どこまで決まっているか**
```
まだ何も決まっていません。まず、いちばん簡単なものから1つ一緒に作ってください。
```

**聞かれたこと：実績・画像・動画など、私が持っていないもの**
```
それは持っていません。ないものは作らず、今ある材料だけでできる形にしてください。
```

## 3. 中身一覧

```
README.md
insta-ai-create/        手順書の本体（SKILL.md と references/ の24本、合計25ファイル）
動画編集/
  howto_<形式>.md       形式ごとの作り方（5本）
  指示文_<形式>.md      AIに貼る指示文（5本）
  作例一覧.md           作例の題名・形式・こんな人に
```

- `動画編集/指示文_アフレコ.md`：顔や声を出さず、自分の声（アフレコ）に生活映像を合わせて作りたい人。
- `動画編集/指示文_VLOG.md`：朝から外出までなど、日常を撮って説明につなげたい人。
- `動画編集/指示文_トーク.md`：自分が話す映像があり、実績などを部品として差し込みたい人。
- `動画編集/指示文_ランキング.md`：紹介したいもの（ツール・商品・方法）が複数あり、順位をつけて見せたい人。
- `動画編集/指示文_比較.md`：2つの考え方や2人を並べて、違いを見せたい人。

## 4. 動画編集の使い方

編集ソフトは使いません。AIが動画を組み立てます。Claude Code か Codex を、素材を置いたフォルダで開いて使います。

1. `動画編集/作例一覧.md` の「こんな人に」を読んで、形式を1つ選びます。
2. `動画編集/howto_<形式>.md` の「用意するもの」を見て、素材を1つのフォルダに集めます。
3. `動画編集/指示文_<形式>.md` を開き、全文をコピーして、AIに貼ります。
4. 素材の名前や、出したい場面を聞かれたら、上の「こう返す」を使って答えます。
5. 出てくるもの：編集指示書（何秒に何を出すかの表）と、動画を書き出す手順です。手順どおりに実行すると、mp4 ができます。

## 5. 詰まったとき3点

1. **貼ったのに動かない**：置き場所が違う場合が多いです。Claude Code は `.claude/skills/insta-ai-create/SKILL.md`、Codex は `~/.codex/skills/insta-ai-create/SKILL.md` があるか、次で確認します。
```bash
ls .claude/skills/insta-ai-create/SKILL.md ~/.codex/skills/insta-ai-create/SKILL.md
```
2. **アプリで手順書として動かない**：ファイルの添付と、手順書としての登録は別です。`SKILL.md` の全文を、入力欄に貼って始めてください。
3. **動画編集で動画ツールが見つからない**：次を打って、エラーになったら、AIに「このパソコンに ffmpeg を入れる手順を教えて」と聞きます。
```bash
ffmpeg -version
```
