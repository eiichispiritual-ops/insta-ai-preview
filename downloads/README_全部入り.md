# インスタAI 全部入りパック

「スキル」は、AIに渡す手順書のことです。このパックには、その手順書と、リール動画の編集の指示文が入っています。
上から順に、押す・打つ・貼るだけで始められます。動画を見る必要はありません。

## 目次

1. 3ステップ（AIごと。ターミナルの開き方・インストール・作業フォルダを含む）
2. AIに聞かれたら、こう返す
3. 中身一覧
4. 動画編集の使い方
5. 詰まったとき3点
6. 置き場所が違うとき

## 1. 3ステップ

先に、使うAIを1つ選びます。迷ったら「ChatGPT・Claude のアプリ」で始めてください。あとから切り替えても無駄になりません。ターミナル（文字で Mac に指示を出す画面。打ち間違えても壊れません）を使うのは Claude Code（Opus 5.5）と Codex（Astra）だけです。この手順は Mac で行います（サイトの「はじめる」と同じ順・同じ言葉です）。
Windows の人は、「ChatGPT・Claude のアプリを使う人」を選んでください。

### Claude Code を使う人

**① 準備する**（ターミナルを開く → Claude Code を入れる → 作業フォルダを作る）

ターミナルは、Spotlight（command＋スペース）で「ターミナル」と打って、Enter で開きます。
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
入れたあとに「PATH」の案内（`~/.local/bin is not in your PATH`）が出たら、その案内に書かれた1行をコピーして貼り、Enter を押して、ターミナルを閉じて開き直します。案内が出なかった人は飛ばします。案内と同じ中身の1行は、次のとおりです（ユーザー名は入れなくて大丈夫です）。
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```
入っているか確認します。バージョンの数字が出れば成功です。「command not found」と出たら、上の1行へ戻ります。
```bash
claude --version
```
作業フォルダを作って、その中へ移ります。
```bash
mkdir -p ~/insta-ai && cd ~/insta-ai
```
次に `claude` と打ち、案内に沿ってログインします。「Do you trust the files in this folder?」と出たら、Enter（Yes）を押します。ログインできたら、control＋C（command ではなく、左下の control キー）を2回押して元の画面に戻ります（Claude Code も Codex も同じ。戻らないと、次の行がAIへの質問になってしまいます）（すでに入っている人は、1行目は飛ばします）。以降の手順は、すべてこの作業フォルダ（`~/insta-ai`）の中で行います。

**② zip を置いて、展開する**

Safari は zip を自動で開くことがあります。`mv` で「No such file」と出たら、Safari の設定「ダウンロード後に安全なファイルを開く」を切って、もう一度ダウンロードするか、Chrome でダウンロードします。ファイル名が違えば、その名前で打ちます（例：`insta-ai-all (1).zip` のときは、`mv ~/Downloads/"insta-ai-all (1).zip" ./insta-ai-all.zip`）。

zip（`insta-ai-all.zip`）を、作業フォルダへ移してから、次の4行を貼ります。
```bash
mv ~/Downloads/insta-ai-all.zip .
unzip insta-ai-all.zip -d insta-ai-all
mkdir -p .claude/skills
cp -R insta-ai-all/insta-ai-create .claude/skills/
```
入ったか確かめます。この1行は手で打ちます。`insta-ai-create` と出れば成功です。
```bash
ls .claude/skills
```
`.claude` は隠しフォルダなので Finder には出ませんが、ちゃんと入っています。

**③ AIを開いて、この1行を貼る**
```bash
claude
```
```
インスタAIのスキル（/insta-ai-create）で、私のプロフィールの、表示名と紹介文を作って。質問せず、足りないところは要確認と書いて仮置きで、そのまま案まで出して。
```
出てくるもの：この1行はプロフィール用なので、表示名と紹介文の案と、選んだ理由が出ます。台本（日付とタイトル・台本の本文・撮影メモ）、フィード投稿（ページごとの見出し・本文・配置）、ストーリー（1枚ごとの本文・使う素材）を作る人は、サイトの「はじめる」で作りたいものを選ぶと、言葉と「出てくるもの」が切り替わります。AIが「要確認」と書いた所は、あなたの本当のことに書き換える場所です。

### Codex を使う人

```bash

```
入っているか確認します。バージョンの数字が出れば成功です。「command not found」と出たら、上の `npm install` の行へ戻ります。
```bash
codex --version
```
作業フォルダを作って、その中へ移ります。
```bash
mkdir -p ~/insta-ai && cd ~/insta-ai
```
次に `codex` と打ち、案内に沿ってログインします。「Do you trust the files in this folder?」と出たら、Enter（Yes）を押します。ログインできたら、control＋C（command ではなく、左下の control キー）を2回押して元の画面に戻ります（Claude Code も Codex も同じ。戻らないと、次の行がAIへの質問になってしまいます）（すでに入っている人は、1行目は飛ばします）。`~/insta-ai` が作業フォルダです。以降の手順は、このフォルダでターミナルを開いたまま行い、`codex` もこのフォルダで打ちます。

**② zip を置いて、展開する**

```bash

```
`.codex` は隠しフォルダなので Finder には出ませんが、ちゃんと入っています。上のコマンドで置きます。

### ChatGPT・Claude のアプリを使う人

**① 手順書をコピーする**（サイトの「はじめる」で「ChatGPT・Claudeのアプリ」を選び、手順3で作りたいものを選んでから、「手順書をコピー」ボタンを押します。迷ったら「手順書を全部コピー」でも使えますが、長いので入力欄に入らないことがあります）

**② AIを開く**（新しい会話を始めます）

**③ 貼る**
1. 入力欄に貼って送ります。長いので、AIの返事が出るまで待ちます。
2. 返事が出たら、次の1行を貼って送ります。
```
いま貼った手順書を使って、私のプロフィールの、表示名と紹介文を作って。質問せず、足りないところは要確認と書いて仮置きで、そのまま案まで出して。
```
出てくるもの：この1行はプロフィール用なので、表示名と紹介文の案と、選んだ理由が出ます。台本（日付とタイトル・台本の本文・撮影メモ）、フィード投稿（ページごとの見出し・本文・配置）、ストーリー（1枚ごとの本文・使う素材）を作る人は、サイトの「はじめる」で作りたいものを選ぶと、言葉と「出てくるもの」が切り替わります。AIが「要確認」と書いた所は、あなたの本当のことに書き換える場所です。

サイトを開けない人は、zip の中の `全部入り_アプリ用.md` を開いて全文をコピーし、①のかわりに使います（ボタンと同じ内容です）。`SKILL.md` だけを貼ると、AIが読めない参照資料が出るので、使わないでください。

## 2. AIに聞かれたら、こう返す

質問が来たときの返し方です。3点まとめて来ることもあります。まとめて返してOKです。そのままコピーして、（ ）や〇〇のところだけ書き換えて送ります。

**3点まとめて返す**
```
ジャンルは〇〇です。見る人は、（どんな場面で何に）困っている人です。使える素材は、スマホで撮れる手元の動画と写真です。ないものは作らないでください。私が実際に試したことは（ここに書く）です。ない場合は、見る人への呼びかけで作ってください。
```

**聞かれたこと：ジャンル・見る人・経験（どんな人に、何を届けたいか）**
```
ジャンルは〇〇です。見る人は、（どんな場面で何に）困っている人です。私が実際に試したことは（ここに書く）です。ない場合は、見る人への呼びかけで作ってください。
```

**聞かれたこと：何を作りたいか・どこまで決まっているか**
```
まだ何も決まっていません。まず、いちばん簡単なものから1つ一緒に作ってください。
```

**聞かれたこと：実績・画像・動画など、私が持っていないもの**
```
それは持っていません。ないものは作らず、今ある材料だけでできる形にしてください。
```

## 3. 中身一覧

```
README.md
全部入り_アプリ用.md   アプリに貼る連結済みの1ファイル（サイトの「手順書を全部コピー」と同じ内容。スキルのフォルダの外に置いてあります）
insta-ai-create/        手順書の本体（SKILL.md と references/ の33本、合計34ファイル）。これだけを cp -R します
video-edit/            （動画編集用）
  howto_<形式>.md       形式ごとの作り方（6本）
  prompt_<形式>.md      AIに貼る指示文（6本）
  examples.md           作例の題名・形式・こんな人に
```

- `video-edit/prompt_voiceover.md`：顔を出さず、あとから録った自分の声で、生活映像を合わせて作りたい人。
- `video-edit/prompt_vlog.md`：朝から外出までなど、日常を撮って説明につなげたい人。
- `video-edit/prompt_talk.md`：自分が話す映像があり、実績などを部品として差し込みたい人。
- `video-edit/prompt_abstract.md`：身近な題材を入口に、人が反応する理由を解説し、権威性や実績を部品として差し込みたい人。
- `video-edit/prompt_ranking.md`：紹介したいもの（ツール・商品・方法）が複数あり、順位をつけて見せたい人。
- `video-edit/prompt_comparison.md`：2つの考え方や2人を並べて、違いを見せたい人。

## 4. 動画編集の使い方

編集ソフトは使いません。AIが動画を組み立てます。Claude Code か Codex を、素材を置いたフォルダで開いて使います。

1. `video-edit/examples.md` の「こんな人に」を読んで、形式を1つ選びます。
2. `video-edit/howto_<形式>.md` の「用意するもの」を見て、素材を1つのフォルダに集めます。
3. `video-edit/prompt_<形式>.md` を開き、全文をコピーして、AIに貼ります。
4. 素材の名前や、出したい場面を聞かれたら、上の「こう返す」を使って答えます。
5. 出てくるもの：編集指示書（何秒に何を出すかの表）と、動画を書き出す手順です。手順どおりに実行すると、mp4 ができます。

## 5. 詰まったとき3点

1. **貼ったのに動かない**：置き場所が違う場合が多いです。Claude Code は `.claude/skills/insta-ai-create/SKILL.md`、Codex は `~/.codex/skills/insta-ai-create/SKILL.md` があるか、作業フォルダ（`~/insta-ai`）の中で、次で確認します。
```bash
ls .claude/skills/insta-ai-create/SKILL.md ~/.codex/skills/insta-ai-create/SKILL.md
```
2. **アプリで手順書として動かない**：ファイルの添付と、手順書としての登録は別です。サイトの「手順書を全部コピー」ボタン（または `全部入り_アプリ用.md` の全文）を、入力欄に貼って始めてください。
3. **動画編集で動画ツールが見つからない**：次を打って、エラーになったら、AIに「このパソコンに ffmpeg を入れる手順を教えて」と聞きます。
```bash
ffmpeg -version
```

## 6. 置き場所が違うとき

お使いの版で場所が違う場合は、Claude Code・Codex それぞれのドキュメントの skills の項を見てください。

それでも「insta-ai-create のスキルで」が効かないときは、アプリを使う人と同じ方法に切り替えます。サイトの「手順書を全部コピー」ボタン（または `全部入り_アプリ用.md` の全文）を、AIの入力欄に貼って送ってから、最初の1行を「いま貼った手順書を使って、」で始めて送ります。
