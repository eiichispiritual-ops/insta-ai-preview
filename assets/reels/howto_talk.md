# 作り方：さき「もっちゅりん」（抽象マーケ）（talk）

人物が話す映像に、権威性・実績・案内の決まった部品を差し込む編集（講師の確認済みの型）。部品の見せ方は毎回同じにし、位置は新しい発話に合わせる。コマ＝映像の1枚で、1秒は約30コマ。

## 用意するもの
- 人物が話す撮影映像
- 自分の再生数が分かるスクリーンショット（実績があるとき）
- プレゼントの紹介画像・案内の画像

## 最初の一手
話の順番（題材 → 疑問 → 立場 → 常識をひっくり返す → …）を決める。顔出しなしの人は、アフレコ（生活映像）かランキングから始めるのがおすすめ。

自分の素材での作り方は、受講生の制作デスクで同じ形式の「編集」を相談すると作れます。編集アプリは自分の使うものでかまいません。

## この型の決まり（最初はここだけ守れば形になる）
- 権威性を話す発話（20ジャンル以上を万アカにしてきた等）に、同じ再生数16枚と効果音（SE）を使う
- 16枚はサイズ・位置・重なり順・登場間隔を固定する。人物を前面に出す
- 基本の案内は、AI×インスタの教科書プレゼント → 勉強会。画像と配置は講師が用意した型のものを使う（受講生の手元にはない。自分の動画では自分のプレゼントの紹介画像に置き換える）
- 「実績がバンバン届いています」には、受講生の実績スクリーンショットの連続表示と同期音を毎回同じ型で入れる。実績が無いときは入れない（数字を作らない）
- 挿入位置は新しい発話に合わせる。元の動画の秒数は固定しない

## 出力
次の3つを、この順に作ってください。

### ① 編集指示書（タイムコード表）
私の台本と素材に合わせ、上の流れと同じ列（時間・声・映像・差し込み・字幕）の表を作ります。秒は小数第2位まで。どの素材ファイルのどこ（入点の秒）を使うかも1行ごとに書きます。声の音声ファイルがある時（別録り、または映像の中の声）は、ffprobe で行ごとの長さを測り、表の各行の時間は「声の長さ＋0.3〜0.5秒」を基準にする。声の音声が無い時は、私に「声なしの字幕のみ」か「音声合成（Macなら say コマンド）」かを聞く。音声合成の声は先頭に約0.1〜0.2秒の無音が入る。素材の元の音（環境音）は、見本にない音は足さない方針どおり、声として使う映像以外は既定で消す。
各行には、使う素材ファイル・入点の秒・使う長さ・速度（倍速／スロー。倍率が1.00でない行だけ）を書く。速度の決め方は②の2に従う。
表は私が見て直せるよう、まず表だけを見せて、私の「OK」を待ってから②に進んでください。私がその場にいない設定（自動実行など）で返事を待てない時は、表を作業フォルダに「指示書.md」として保存してそのまま②に進み、最後の報告に「表の確認は未」と書いてください。

### ② ffmpeg で 720×1280・30fps に書き出すコマンド列
幅720・高さ1280の縦画面、毎秒30コマ（30fps）、H.264（再生互換性の高い動画形式）の mp4 にします。手順を1本のシェルスクリプトにまとめ、1行ずつ何をするか一言コメントを付けてください。作業フォルダの中は 素材/（コピーした素材）・cap/（字幕PNG）・build.sh・出力/（完成の out.mp4）に分けます。ffmpeg のフィルタが長くなる時（素材と字幕が合わせて10個を超える時など）は、フィルタ本体を filter.txt に書き出し、-filter_complex_script filter.txt で読み込ませる。
1. 素材をそろえる：各映像を scale=720:1280:force_original_aspect_ratio=increase、crop=720:1280、fps=30、format=yuv420p にそろえ、音声は 48kHz にする。既定は「拡大して余りを切り取る（cover）」で、黒い帯を出さない。この型の決まりに「帯を残す」「枠の中に収める」と書いてある場合や、横長の素材をそのまま見せる場合だけ、scale=720:1280:force_original_aspect_ratio=decrease、pad=720:1280:(ow-iw)/2:(oh-ih)/2 にする
2. 表の時間どおりに trim（切り出し）して並べ、concat（つなぐ）する。切り替えは指示書どおり。表の1行の長さに、使う素材の長さが合わない時（足りない・余る）は速度で合わせる。速度＝素材の長さ÷表の長さ。映像には trim=start=入点:end=入点+素材の長さ,setpts=(PTS-STARTPTS)/速度 を掛け、そのあとに fps=30 をかける。速度2.0なら半分の長さ、0.5なら倍の長さになる（割り算の向きを逆にすると、表の秒に届かない）。速度が0.5未満・2.0超になる時は、無理に伸ばさず、別の素材に替えるか私に聞く。同じ素材を2回使う時は入点を変える。映像の中の声を使う区間は速度を変えない
3. 差し込み画像・字幕PNGを overlay フィルタで重ねる。出す時間は enable='between(t,開始秒,終了秒)' で表の秒に合わせる。静止画のPNGは1コマで終わってしまうので、必ず -loop 1 -framerate 30 -t 動画の全体尺（秒） -i 画像.png の形で読み込む
4. 声・（使う場合のみ）効果音・BGMを amix でまとめる。各音の開始位置は adelay=ミリ秒|ミリ秒 で合わせる。amix は既定で入力の数だけ音量が下がるので amix=inputs=個数:normalize=0 を付ける（normalize が使えない古い ffmpeg では volume で音量をそろえる）。見本にない音は足さない
5. 仕上げ：-c:v libx264 -crf 18 -pix_fmt yuv420p -r 30 -c:a aac -b:a 192k -movflags +faststart 出力/out.mp4

### ③ 字幕PNGの作り方
字幕は、透明背景の PNG（幅720×高さ1280）を字幕1枚ごとに Python（Pillow）で描いて作り、②で重ねます。
- 日本語フォントは、私のパソコンに入っているものを探して使う。Macは /System/Library/Fonts/ の中の「ヒラギノ丸ゴ ProN W4.ttc」を優先し、見つからなければ ls でファイル名の日本語も含めて探す（fc-list や英字名の grep では見つからないことがある）。Windowsは C:\Windows\Fonts の meiryo.ttc など。どうしても無ければ私に聞く。見本の書体と同じでなくてよく、近い見た目で読みやすければよい
- 1画面は1〜2行。長い文は区切りのよいところで改行する
- 文字の色・帯（文字の後ろの四角）・置く位置は、上の「字幕と音のコツ」に従う。そこに指定がない項目の既定値は、文字の大きさ40〜48px・帯は黒で透明度60%（alpha 150）・帯の中心は縦の中ほど（y=640）・帯の余白は左右34px、上下22px・角丸18px・1行は全角16文字まで
- 字幕の表示時間は、表の「字幕」列の時間に合わせる

## 確認（書き出したあと、必ず自分で見て報告する）
- ffmpeg で数か所（最初・中ほど・最後と、差し込みの出入り直前直後）を静止画に書き出して見る。真っ黒・色の抜け・画面のはみ出しがないか
- 音ずれ（書き出したあとに数字で測る。耳や目だけで決めない）：声だけを表の位置に並べた音声（voice_only.wav。②と同じ adelay で作り、他の音は入れない）と、書き出した out.mp4 の音声を、どちらも 16kHz・モノラルの wav に変換し、Python（numpy）の相互相関（np.correlate または FFT）で「何秒遅れているか」を出す。遅れが ±0.1秒以内でなければ、その分を adelay で直して書き出し直す（声が遅れていれば adelay を減らす）。あわせて ffmpeg -af silencedetect=n=-40dB:d=0.25 で各行の声の立ち上がり秒を出し、表の字幕の開始秒との差も ±0.1秒以内か見る（音声合成の声は先頭に無音があるので、その分も adelay で引く）。映像の中の声を使う型は、元の映像の音声と out.mp4 の音声で同じ測り方をする
- 字幕の読みやすさ：背景に埋もれていないか、顔や差し込みを隠していないか、1画面の文字量が多すぎないか、素材に焼き込まれた文字と重なって読みにくくなっていないか
- ffprobe で 720×1280・30fps・音声ありになっているか、長さが完成の目安尺に収まっているか（0.5秒以上ずれていれば私に伝える）
見つけた問題は直してから、「確認した点」と「直した点」を私に伝えてください。
