# 作り方：さき「もっちゅりん」（抽象マーケ）（talk）

人物が話す映像に、権威性・実績・CTAの決まった部品を差し込む編集（さき抽象マーケ・承認済みの型）。部品の見せ方は毎回同じにし、位置は新しい発話に合わせる。

## この型の決まり
- 権威性を話す発話（20ジャンル以上を万アカにしてきた等）に、同じ再生数16枚とポップSEを使う。小さい8枚の旧版には戻さない
- 16枚はサイズ・位置・重なり順・登場間隔を固定する。人物を前面に出す
- 基本CTAはAI×インスタの教科書プレゼント → 勉強会誘導。画像と配置は承認マスターのものを使う
- 「実績がバンバン届いています」には、受講生実績スクショの連続表示と同期音を毎回同じ型で入れる
- 挿入位置は新しい発話に合わせる。元の本の絶対秒数は固定しない

## 守ること
- 新しい本の字幕は、台本の文面に合わせて打ち直す
- 顔・字幕を隠さない
- 旧作の話し声が入ったミックス音声は、新作へ流用しない。余計な音楽を足さない
- プレゼント名・実績スクショを作り直さない。数字・成果を作らない
- 本文誘導にプロフィール写真を足さない

## 使う素材
- 再生数16枚（再生数フォルダ）＋ポップSE16回
- CTA画像：教科書プレゼント・勉強会（CTA画像フォルダ）
- 受講生実績スクショ（承認マスターの素材）
- 人物の撮影映像（新しい人物用の前景マスクを作り直す）
- 承認マスター（Premiere。別名コピーで使う）
