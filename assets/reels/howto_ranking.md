# 作り方：さき「無料ツールランキング」（ranking）

画面の左に空の順位表を置き、紹介のたびに埋めていく編集。紹介順と順位は別に管理し、切り替えはすべてハードカットにする。

## この型の決まり
- 紹介順と順位は別物（論外 → 2位 → 4位 → 3位 → 1位）
- 切り替えは中央ロゴ → 順位の文字 → 表内ロゴの順。1フレームで切り替える
- 飛翔（ロゴが縮みながら表へ動く）・フェード・スライドは足さない
- 1位だけ「ため」を作る。中央ロゴを消して18フレーム、字幕『圧倒的』だけ見せてから順位の文字を出す
- 締めは見出し・名札・順位表を同時に外し、配布物3枚を2フレーム刻みで出す

## 守ること
- 字幕は白い細い文字＋暗い半透明の矩形。本編は順位表を避けて中心x≈776、締めは中央x≈540
- 中央ロゴと順位文字のあいだは字幕を出さない
- 作例は説明の意味に合わせて出し、説明が終わったら消す
- CTAは本文誘導だけ。プロフィール画像・教科書・勉強会CTAは入れない
- 見本にないBGM・SEは足さない（1位のSEの有無は未確認）

## 使う素材
- 撮影原本（テロップなしの人物映像）
- ツールのロゴ（アイコン：ChatGPT・Vrew・CapCut・Nano Banana）
- 作例画像・画面録画（さき素材）
- 配布物3枚：チラシ・LP・ストーリー用縦画像（さき素材）
- 順位表・見出し帯・順位文字（描画）
