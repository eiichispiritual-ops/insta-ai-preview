01 / AIが作った作例

この動画が、
AIで作れる。

形式ごとに、人が編集した見本とAIの再現を並べています。
各カードの「こんな人に」を読んで、自分に近い形式を1つだけ選んでください。
差の数字は0に近いほど見本に近く、「作り方」は最初の一手から読めます。
「見本と同等」は数値の比較で基準内だったもの、「講師の確認済み」は講師が見て確認したもの、「改善を続けている作例（数値は見本との差）」は、見本との差が残る場面を数値で確かめながら直している作例です（AIの失敗例ではありません）。再現は撮影原本から作り、見本の映像・音は使っていません。

  1. 1

    いつも使っているAIを選ぶ

    Windows・iPad・スマホの人は、「ChatGPT・Claudeのアプリ」を押します。

    迷ったら「ChatGPT・Claudeのアプリ」で始めてください。あとから切り替えても無駄になりません。ターミナル（文字で Mac に指示を出す画面。打ち間違えても壊れません）を使うのは Claude Code と Codex だけです。

    ChatGPT・Claudeのアプリ：いちばん簡単。いつもの ChatGPT や Claude に貼るだけ（ターミナル不要）。台本・プロフィールなどの文章を作れます。
    Claude Code・Codex：動画まで作れます。

  2. 2

    手順書をAIに渡す（コピーして貼るだけ）

    先に、作りたいものを選んでください（選ぶのはここだけです）

    動画まで作るには Claude Code か Codex が要ります（自動では切り替えません。使いたいときは、上の手順1で選び直します）。

    スマホ・iPad の人：コピーしたら ChatGPT・Claude のアプリを開き、新しい会話の入力欄を長押し → ペースト → 送信します。返事が出たら、このページに戻ります（ブラウザのタブを切り替えます）。

  3. 3

    最初のひと言をコピーして、AIに貼る

    作りたいもの

    スマホ・iPad の人：コピーしたら、アプリの同じ会話の入力欄を長押し → ペースト。貼ったら、このページに戻ります（ブラウザのタブを切り替えます）。

AIに質問されたら、こう返す

AIの質問は、3点まとめて返してOKです。ボタンを押してコピーして、（ ）のところだけ書き換えて貼ります。AIが「要確認」と書いた所は、あなたの本当のことに書き換える場所です。

03 / 2分34秒

リールの台本を1本作る

最初のひと言をコピーしてAIに貼り、台本が出て、1つだけ直すまで。

動画

この動画で分かること

撮った素材から動画を書き出す

素材をフォルダにまとめ、編集指示書の表にOKを出し、動画の書き出しまで（Claude Code か Codex）。

動画

この動画で分かること

  • 形式は、撮った素材で決まる（アフレコ・VLOG・トーク・ランキング・比較）

      コピーしたあと、どこに貼るか

      • Claude Codeプロジェクトの .claude/skills/insta-ai-create/SKILL.md に、コピーした内容を貼って保存します（zipなら、展開した insta-ai-create フォルダごと .claude/skills/ に置きます）。Claude Codeを開き、「/insta-ai-create」と入力するか、「インスタAIのスキルで台本作って」と話しかけます。
      • Codex~/.codex/skills/insta-ai-create/SKILL.md に、コピーした内容を貼って保存します（zipなら、展開した insta-ai-create フォルダごと ~/.codex/skills/ に置きます）。Codexで「インスタAIのスキルで台本作って」と話しかけます。

    4. 4

      詰まりやすいところ

      • 「スキル」が分からないAIに渡す、手順書と決まりの束です。料理のレシピに近いものです。
      • 貼ったのに動かないファイルの置き場所が違う場合が多いです。Claude Codeは .claude/skills/insta-ai-create/、Codexは ~/.codex/skills/insta-ai-create/ の中に SKILL.md があるか確認してください。
      • 使える機能が見当たらないサービスやプランによって違います。その場合は、アプリの入力欄にそのまま貼る方法で始められます。

    よくある質問

    始める前に、よく聞かれること。

    まだ台本を書いたことがなくても？+

    まずは、届けたい相手と自分が見せられるものから整理します。最初から全部の形式を覚える必要はありません。教材の必要な箇所を読み返しながら進める設計です。

    形式は、ひとつに決めるもの？+

    組み合わせられます。ランキングや比較は話の構成です。この教材のアフレコ形式は、人物紹介や経験から本題へ入る型です。VLOGにあとから声を入れたり、比較をトークで説明したり、内容と素材に合わせて考えます。

    いつものChatGPTやClaudeでも使える？+

    使えます。アプリでは、コピーした手順書を新しい会話に貼れば始められます。動画まで作れるのは、Claude CodeとCodexです。登録方法や使える機能は、サービスやプランによって異なります。

    今、このページでできることは？+

    こちらでは投稿の作例と相談メモを確認できます。スキルは全体を公開していて、コピーとzipのダウンロードができます。受講生の制作デスクにはログインと履歴保存があります。このページに出る回答は作例で、生成AIの実回答ではありません。
