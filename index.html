外注している動画を、AIで同じ作りにする

テロップ入れ・カット・BGM といった定型の編集を、外注に出さずに自分の Mac で回すための手順です。外注先から納品された動画を1本選び、テロップの字体や位置、カットの間、BGM、冒頭と締め、PR部分まで AI に測らせます。同じ撮影素材から作り直して見本と並べ、ずれを型（my-style.md）に書き戻す。これを差が気にならなくなるまで続けます。型ができれば、次からは素材を渡して一言頼むだけです。

    比べるところと、近づけるコツ

    毎回この順で見ます。
    1. 同じ秒の静止画（冒頭、カット直後、テロップの出入り、PR部分、締め）
    2. テロップの位置、大きさ、色、字数、出る秒
    3. カットの秒
    4. 音量
    5. コマごとの差の数値

    1回に直すのは1〜2か所にしてください。字体や大きさ、位置のように目立つずれから直すと早く近づきます。数値はカットごとに見ます。動画全体の数値だと、1か所の大きなずれに埋もれてほかの改善が見えなくなるためです。AIは「同じになった」とは判断せず、残っている差を数値と画像で出します。

著作権・フォント・契約について

見本にするのは、自分のアカウントで投稿した自分の動画に限ります。外注先のテンプレートや購入素材は契約で使い方が決まっていることがあるので、先に確認してください。BGM は見本から抜き出さず、正規に入手した音源を使います。フォントのライセンスもご自身で確認してください。

「見本と同等」：数値の比較で基準内に収まったもの。

ファインダーで素材フォルダを右クリックし、オプションキーを押します。パス名としてコピー、を選ぶと、その場所をコピーできます。

ページで動画編集を選び、素材のフォルダ欄に、コピーした場所を貼ります。画面の場所は記入例なので、自分の場所に置き換えます。

声と映像を別に撮ったなら、アフレコ。話している映像ならトークなど、撮った素材に合う形式を選びます。

最初の依頼と、作り方を送る

最初のひと言をコピーして、準備済みのエーアイに送ります。続いて、下の、作り方の指示文も、同じ会話に送ります。

素材を読めないと言われたら、場所が合っているか、ファイルを開けるか確認します。分からないまま書き出しへ進めません。

編集指示書は、動画の設計図

最初に出てくる編集指示書は、何秒に、どの声と映像、どんな字幕を出すかを並べた表です。これは動画の設計図です。

例えば、最初の三秒は困りごと、次の三秒は手元の映像。ここでは、説明用の例を表示しています。

まずは、表の3点を確認

表では、声と映像が合うか、字幕に間違いがないか、持っていない素材が指定されていないかを確認します。

違うところがあれば、何行目の、どこを直すか伝えます。例えば、二行目の字幕だけ短くしてください、で大丈夫です。

表でOKなら、書き出しを頼む

表がよければ、表でオーケーです。書き出してください、と送ります。書き出しとは、再生できる動画ファイルにすることです。

処理中は完了の返事を待ちます。このページの標準の保存先は、インスタエーアイの出力フォルダにある、アウト、ドット、エムピーフォーです。

できた動画を、最後まで再生する

完了したらファインダーで、コマンド、シフト、ジーを押します。画面の出力フォルダの場所を貼ってエンター。アウト、ドット、エムピーフォーをダブルクリックします。別の保存先が返ったら、その場所を開いてください。

完成した動画を、音を出して最初から最後まで見ます。声が聞き取れるか、字幕を読み切れるか、黒い画面や抜けがないかを確認します。

字幕が顔や大事な物に重なっていないかも見ます。パソコンだけでなく、投稿を見るスマホの大きさでも確かめましょう。

修正は「秒数＋変える内容」で

直すときは、八秒の字幕を二行にして、など、秒数と変える内容を一緒に伝えます。

元の動画を残し、別の名前で保存してもらうと比較できます。直した場所と、その前後をもう一度見てください。

いつもの編集に近づけたいとき

いつもの外注動画に近づけたい方は、ページの、自分の型、へ進みます。見本の完成動画と、元の撮影素材を用意します。

一度で同じになると決めつけず、作り直して、比べて、違うところを直す。この確認までが、動画編集です。

    迷ったときの3つの問い

    台本の候補が決めきれないときは、この3つを上から順に確かめます。AIに「この3つで候補を比べて」と頼んでも使えます。

    01

    見た人は、どこで困っているか

    年齢やジャンルより、投稿を見た瞬間にその人が何に困っているかを先に考えます。

    02

    手元の素材で何を見せるか

    自分で撮れるもの、試した結果、経験。用意できる材料から企画を決めます。

    03

    その一文と順番にした理由は何か

    候補を並べて比べ、選んだ理由を残しておきます。台本でも撮影メモでも同じです。

    よくある質問

    台本を書いたことがないのですが+

    最初は「誰に見せたいか」と「自分が見せられるもの」を書き出すところからで十分です。形式は作りながら覚えていけます。

    形式は1つに絞るものですか+

    組み合わせてかまいません。ランキングや比較は話の組み立て方で、アフレコは人物紹介や経験から本題に入る型です。VLOGにあとから声を入れる、比較をトークで話す、といった使い方もします。

    いつもの ChatGPT や Claude でも使えますか+

    使えます。コピーした手順書を新しい会話に貼れば始められます。動画の書き出しは Claude Code と Codex のみです。登録の方法や使える機能はサービスとプランによって違います。

    このページで何ができますか+

    作例を見ること、相談メモを作ること、手順書をコピーまたは zip で受け取ることです。ページに出てくる作例・進め方の例・サンプルはすべて説明用に作ったもので、AIがその場で答えたものでも、実際の投稿実績でもありません（リールの作例だけは、実際の動画です）。
