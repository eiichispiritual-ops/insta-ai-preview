    HOW TO GET THE SKILL

    スキルは、
    そのままコピーして使う。

    スキルは全体を公開しています。作りたい入口のボタンを押すと、SKILL.mdと、その入口で使う参照資料が1つのテキストになってコピーされます。zipで一式をまとめて受け取ることもできます。

    1. 1

      作りたいものを選んで、コピーする

      ボタンを押すとコピーされ、「コピーしました」と表示されます。コピーできない環境では、全文が表示されるので、選択してコピーしてください。

      全部やりたい人はこちら

      全部入りパック（zip）スキル一式（SKILL.md＋参照資料24本）と、リール5形式の動画編集の作り方・指示文・作例一覧、入れ方の README が入っています。約98KB。

      README だけ先に読む →

      プロフィール・フィード・ストーリー

      リール（形式を選ぶ）

      動画編集（形式を選ぶ）

    2. 2

      一式をまとめて受け取る（zip）

      SKILL.mdと参照資料24本（合計25ファイル）を、フォルダの形のまま入れたzipです。ファイルとして置きたいときに使います。
      スキル一式をダウンロード（insta-ai-create.zip） ↓

    3. 3

      使い方

      • Claude Code（Opus 5.5）プロジェクトの .claude/skills/insta-ai-create/SKILL.md に、コピーした内容を貼って保存します（zipなら、展開した insta-ai-create フォルダごと .claude/skills/ に置きます）。Claude Codeを開き、「/insta-ai-create」と入力するか、「インスタAIのスキルで台本作って」と話しかけます。
      • Codex（Astra）~/.codex/skills/insta-ai-create/SKILL.md に、コピーした内容を貼って保存します（zipなら、展開した insta-ai-create フォルダごと ~/.codex/skills/ に置きます）。Codexで「インスタAIのスキルで台本作って」と話しかけます。
      • ChatGPT・Claudeのアプリコピーしたテキストを、新しい会話の入力欄にそのまま貼って送信します。貼り方の詳細は skill-use.txt にあります。
    4. 4

      詰まりやすいところ

      • 「スキル」が分からないAIに渡す、手順書と決まりの束です。料理のレシピに近いものです。
      • 貼ったのに動かないファイルの置き場所が違う場合が多いです。Claude Codeは .claude/skills/insta-ai-create/、Codexは ~/.codex/skills/insta-ai-create/ の中に SKILL.md があるか確認してください。
      • 使える機能が見当たらないサービスやプランによって違います。その場合は、アプリの入力欄にそのまま貼る方法で始められます。

    06 / MADE BY AI

    この動画が、
    AIで作れる。

    この講座の AI が、見本と同じ編集を再現した作例です。形式ごとに、人が編集した見本とAI再現を並べています。各カードの「こんな人に」を読んで、自分に近い形式を1つ選んでください。
    差は全フレームを数値で比べた実測値で、0に近いほど見本に近い数字です。下の「作り方」は、その動画の編集メモで、最初の一手から読めば始められます。
    「見本と同等」は数値の比較で基準内だったもの、「講師の確認済み」は講師が見て確認したもの、「改善を続けている作例（数値は見本との差）」は、見本との差が残る場面を数値で確かめながら直している作例です（AIの失敗例ではありません）。再現は撮影原本から作り、見本の映像・音は使っていません。

    02 / 3分

    スキルとは

    「スキル」という最初の壁を、身近なたとえで片づける。

    動画

    この動画で分かること

    • スキルは、AIに渡す手順書と決まりの束（料理のレシピに近い）
    • zipの中身（SKILL.md と references）と、貼る場所の考え方
    • 登録しなくても、相談メモだけで始められること

    • 登録の可否はサービス・プラン・環境で異なる。自動登録とは言わない
    • 登録なしでも、相談メモに中身が入っているので始められる

    04 / 5分

    動画編集の使い方

    撮った素材から、何を・どこで・どれだけ出すかを決める。

    動画

    この動画で分かること

    • 撮った素材から形式を選ぶ（時間順ならVLOG、声と別撮りならアフレコ）
    • 「この動画の作り方」を上から順に読む方法
    • 自分の素材に当てはめて、仕上げを確認するところまで
    台本の要点を見る+
    • ボタン操作は扱わない。編集アプリはお好きなもので大丈夫
    • 素材で形式を決め、混ざるときは長い部分の形式を主にする
    • 作り方は、用意するもの→最初の一手→型の決まり→字幕と音のコツの順
    • 仕上げはスマホで通して見て、直す点を一つ決める

    A FEW THINGS TO KNOW

    使う前に、知っておきたいこと。

    まだ台本を書いたことがなくても？+

    まずは、届けたい相手と自分が見せられるものから整理します。最初から全部の形式を覚える必要はありません。教材の必要な箇所を読み返しながら進める設計です。

    形式は、ひとつに決めるもの？+

    組み合わせられます。ランキングや比較は話の構成です。この教材のアフレコ形式は、人物紹介や経験から本題へ入る型です。VLOGにあとから声を入れたり、比較をトークで説明したり、内容と素材に合わせて考えます。

    ChatGPTやClaudeで使える？+

    共通のMarkdownスキルを用意しています。登録方法や使える機能は、サービス・プラン・実行環境によって異なります。普通のチャットへファイルを添付することと、スキルとして登録することは別です。

    今、このページでできることは？+

    こちらでは投稿の作例と相談用Markdownを確認できます。スキルは全体を公開していて、コピーとzipのダウンロードができます。受講生の制作デスクにはログインと履歴保存があります。このページに出る回答は作例で、生成AIの実回答ではありません。
