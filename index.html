AIメンターくん

今、どこから
手をつければいい？

インスタで累計15億、20ジャンル以上で万アカ（1万フォロワー以上のアカウント）を育ててきた運用ノウハウをもとに、あなたの次の一歩をサポートします。

「投稿が続かない」「見られても相談や予約につながらない」「編集に時間がかかりすぎる」——。
目標と今の状況をもとに、次に取り組むことをAIと一緒に整理。台本・編集・ストーリー・フィードの制作から、実践後の振り返りまで相談できます。

1つのテキストファイルを ChatGPT か Claude に渡すだけで始められます（専用ソフトのインストールなどは不要です）。最後に「開始文」を送ると、AIが1つずつ質問しながら現状の整理をナビゲートします。

ファイルを渡して、相談をはじめる

  1. 相談ファイルをダウンロードする

    AIへの手順書と参照資料がまとまった1つのテキストファイルです。中身を開いて確認する必要はなく、そのままAIに添付して使えます。

    相談ファイルをダウンロード（.txt）

    ファイル名：AIメンターくん.txt。通常は端末の「ダウンロード」フォルダに保存されます。見つからない場合はブラウザのダウンロード履歴をご確認ください。

  2. 開始文をコピーして、普段使っているAIを開く

    手動でコピーする場合は、上の文章を選択して ⌘C（Windowsは Ctrl+C、スマホは長押し→コピー）を押します。コピーしたら、下のボタンからAIを開いて新しいチャットを作ってください。迷ったら普段使い慣れている方で大丈夫です。

    ChatGPTを開く ↗ Claudeを開く ↗

    ※別タブで開きます（各サービスへのログインが必要な場合があります）。このページ上ではAIの回答は表示されません。

  3. ファイルを添付し、開始文を貼り付けて送信する

    AIのメッセージ入力欄へ、手順1で保存したファイルをドラッグ＆ドロップします（スマホの場合は「＋」などの添付ボタンからファイルを選びます）。

    ファイル名が表示され、読み込みが完了したら、手順2でコピーした開始文を貼り付けて送信してください（Macは ⌘V、Windowsは Ctrl+V、スマホは入力欄を長押し→「ペースト」）。

    AIから最初の質問が返ってきたら準備完了です。分かる範囲で答えていき、その後も同じチャット画面で相談を続けてください。

ファイルの添付や送信がうまくいかないとき

※ファイルを添付しただけでは相談は始まりません。必ず上の「開始文」も一緒に送ってください。
もしファイルを添付できない場合や、AIに「ファイルを読めない」と言われた場合は、下のボタンを押すと「手順書」と「相談内容」をテキストとしてまるごとコピーできます。AIの入力欄にそのまま貼り付けて送信してください。長い文章がテキストのカードとして表示されても、そのまま送信できます。

ファイル添付の可否や文字数の上限は、お使いのAIサービスや料金プランによって異なります。別の新しいチャットでやり直す場合は、もう一度ファイルを添付してください。

「送信に失敗しました」と表示されたら、画面にある「再試行」ボタンを押してください。すでにAIから回答が返ってきている場合は、送り直さずにそのまま会話を続けて大丈夫です。利用制限（回数上限）の案内が出た場合は、表示された再開時刻まで待ってからお試しください。

相談内容を先に書いてから始める（任意・コピーして使う）

※ここは空欄のまま始めても大丈夫です。先に状況を書いておきたい場合は、ここに入力してからダウンロードすると、ファイルの中に相談内容が自動で組み込まれます（内容を書き換えた場合は、もう一度ダウンロードしてください）。

さらに詳しい状況を伝える（任意）

※ご自身の相談だけでなく、クライアントや受講生からヒアリングした内容をそのまま入力して使うことも可能です（氏名や連絡先などの個人情報は入力しないでください）。入力内容がこのページから外部へ自動送信・保存されることはありません。

続きは同じチャットに「やってみた結果」や「できなかったところ」を送るだけ。別のチャットへ移るときは「引き継ぎメモを作って」と頼み、このページの相談ファイルとメモ、必要な原稿を一緒に渡してください。

2回目からは、同じチャットへ。「やってみた結果」や「できなかったところ」を送ると、前回の続きから相談できます。区切りには「引き継ぎメモを作って」と頼んで保存しておくと、別のチャットでも再開しやすくなります。

AIメンターくんでは、どんなことを一緒に整理できますか？

① いま作業が止まっている箇所と、次に確認すべきポイント
② なぜそこから手をつけるのが一番近道なのか（理由の整理）
③ 投稿の下書きや撮影メモなど、今日すぐ進められる小さな一歩
④ 実践した結果の振り返りと、次の投稿で変える一点
⑤ 急成長・継続型・他ジャンルの参考を使い分け、約50投稿の比較から自分の改善案へ

※手元にインサイトの数字や原稿がそろっていなくても、原因を決めつけずに現状の確認から一緒に始めます（AIがあなたのInstagramアカウントへ勝手にログインして非公開データを調べるような機能ではありません）。

継続相談の手順書 v3.3。更新版を使うときはファイルを取り直し、続けているチャットへ渡してください。過去に渡した内容は自動更新されません。大切な原稿や引き継ぎメモは、ご自身でも保存してください。

    使うAIを選ぶ

    スマホ・iPad・Windows の方は「ChatGPT・Claude のアプリ」を選んでください

    それぞれの違いを見る（タップで開く）

    迷ったら、まずは一番手軽な「ChatGPT・Claude のアプリ」から始めてみてください。あとから Mac の Claude Code や Codex に切り替えても、作った台本はそのまま引き継げます。

    手順書をAIに渡す

    何を作りますか？

    最初のひと言（今回の依頼文）を貼る

    作りたいもの

    「ジャンル」には、何について発信したいかを短く入れます（例：「副業の始め方」「時短レシピ」など）。まずは1本目を作るための仮テーマで構いません。まだ思いつかない場合は空欄のままでOKです。普段のお仕事や日常でやっていることからAIと一緒にテーマを見つけられます。

    さらに具体的に指定する（任意）：届けたい相手・悩み・伝えたい工夫+

    手順2で手順書を送った同じチャット画面に貼り付けて、そのまま送信してください（新しいチャットは開きません）。

    手順書を送った元のチャット画面を見失ってしまったとき

    AIのチャット履歴から、直前に手順書を送ったスレッドを探してみてください。もし見つからない場合は、下のボタンを押すと「手順書」と「今回の依頼文」を1つにまとめてコピーできます。新しいチャット画面に貼り付けて、最初からやり直せます（※以前のチャットでの会話内容は引き継がれません。残したい原稿がある場合は、同じチャット内に続けて貼り付けてください）。

AIから質問が返ってきたら

質問には1回の返信でまとめて答えて構いません。下の定型文をコピーし、（ ）の中をご自身の内容に書き換えて送ってください。出てきた台本に「【要確認】」がある場合は、ご自身の実際のエピソードや数字に差し替えます。

一度にたくさん指示するより、「1回につき1か所ずつ」修正を頼むと、狙いどおりの自然な文章に仕上がります。

続けて動画の編集・書き出しも行う場合

選んだ形式専用の「編集指示文」をコピーして、同じチャット画面に続けて貼り付けます。

素材フォルダの準備方法が分からないとき

ターミナルを開いて command＋N を押し、新しいウインドウに下のコマンドを貼って Enter を押すと、専用の「素材フォルダ」が作られて自動で開きます。撮影した動画・録音した音声・画像をこのフォルダの中へコピーしてください。また、完成した台本は Mac の「テキストエディット」に貼り付け、上部メニューの「フォーマット → 標準テキストにする」を選んでから、台本.txt というファイル名で同じ素材フォルダに保存します（手順3の素材欄には ~/insta-ai/素材 と入力します）。※元のデータが消えないよう、必ずファイルを「移動」ではなく「コピー」して入れてください。

フォルダに素材を入れたら、起動中のAIのチャット画面へ戻り、下のボタンの文章を送って中身を確認してもらいます。ファイル名が正しく認識されていることを確かめてから、実際の編集へ進みましょう。

ChatGPT や Claude のスマホ・Webアプリ版で作成できるのは、「編集の段取り表（何秒目に・どの映像と声・どんな字幕を入れるかの設計図）」までです。表ができたら、①編集アプリ（CapCutなど）に動画素材を読み込む → ②段取り表の秒数通りに並べる → ③音声と字幕のタイミングを合わせる → ④動画を書き出す → ⑤音を出して最初から最後まで再生確認する、の順で仕上げてください。もし Mac で動画の自動編集・書き出しまでAIに任せる場合は、手順1で「Claude Code」または「Codex」を選び、A・B・C の初期設定を行ってください。

完成させる前の最終チェック

外注している動画の「編集スタイル」を、AIで再現する

テロップ配置・ジェットカット・BGM調整といった定型の動画編集を、外注に出さず自分の Mac で完結させるための手順です。過去に外注先から納品された完成動画を1本選び、テロップのフォントや位置、カットの間隔、BGMの音量、冒頭・締め・PRパートの構成までAIに細かく計測させます。そのデータをもとに同じ撮影素材からAIに動画を組ませ、見本と並べて比較し、ズレがあれば「自分の型（my-style.md）」のルールを更新します。見本との差を比較し、気になる箇所を調整して仕上げます。必要な回数は素材や編集内容で変わります。一度「型」ができれば、次回からは新しい撮影素材を渡して一言頼むだけで、同じテイストの動画が書き出せます。

→
1. 見本を測る2. 同じ素材で組む3. 並べて直す4. 型を仕上げる5. 新しい素材で量産

外注コストとの比較目安「自分の型」を作ることで、対応できる定型編集を手元の Mac で進められます。「1本あたりの外注費 × 月間の投稿本数」と、最初の型づくりにかかる作業（見本1本を計測し、数回比較して微調整する手間）に加え、AIツール費・素材準備・毎回の確認や修正にかかる時間を含めて比べてください。※なお、型ができたあとも、誤字脱字や微妙な改行バランスの最終チェックはご自身の目で行います。

用意するもの① Mac の Claude Code または Codex（上の「はじめる」の手順2で A・B・C の初期設定を終えた状態） ／ ② お手本にしたい完成動画1本と、その動画を作ったときの「編集前の撮影素材（外注先に渡した元動画や音声ファイル）」

※初めての方は、先に「はじめる」のセクションでAIと手順書の初期設定を済ませてください。準備ができたら、画面上部のメニュー「外注編集をAIで」からいつでもここへ戻れます。

手直ししたい箇所があるときは、一度に全部言わず「まずは1か所だけ」伝えるのがコツです。たとえば「冒頭の1行目だけ、別の切り口で3案出してください」のように頼みます。ページの「出てきた原稿を手直ししたいとき」の欄にも、ワンタップでコピーできる修正指示文を用意しています。冒頭・全体の長さ・話し方のトーンを1つずつ順番に直していくと、狙いどおりに仕上がります。

普段外注している動画や、自分のいつもの編集スタイルにそっくり近づけたいときは、ページの「外注編集をAIで」のセクションを開いてください。お手本にする完成動画1本と、その撮影素材を使って「自分の型（my-style.md）」を作ることで、テロップの位置やカットの間隔、音の入り方まで自分のスタイルに合わせて自動化できます。

操作の途中で迷ったら：元のチャット画面を見失ったとき ／ リールの形式を選べないとき ／ 完成後のチェックと手直し。動画を一時停止し、該当する案内を開いて進めてください。

音声：AIナレーション（日本語）。動画内のファイル名や編集表は説明用のサンプルです。参考：Macでファイルやフォルダのパスを指定する方法（Apple公式）

リールのほかに、フィードとストーリーも

同じ手順書を使って、フィード投稿やストーリーの原稿も作成できます。

フィード投稿

リールで話したテーマは、そのままフィード投稿にも展開できます。表紙・悩みの場面・具体例・考え方・完成イメージを1枚ずつに分けることで、読者が自分のペースで読み返せる投稿になります。

  • 出力されるもの：ページごとの原稿とレイアウトのメモ
  • 用意するもの：「誰に届けたいか」と「伝えたい工夫」を1つ

ストーリー

日常の発信、質問箱への回答、企画の振り返りなど、目的に合わせた1日分の枚数・順番・各画面の文言を作成します。投稿後の閲覧数（インサイトの数字）を貼れば、次回の改善点も一緒に整理できます。

  • 出力されるもの：1枚ごとの文言・構成順・スタンプの配置場所
  • 用意するもの：その日に起きた出来事や伝えたいこと

    迷ったときの3つの判断基準

    台本の案が絞りきれないときは、上から順にこの3つを確かめてみてください。AIに「この3つの基準で候補を比べて」と頼むこともできます。

    01

    見る人は、どんな場面で困っているか？

    年齢や性別といった属性よりも、「投稿を目にした瞬間に、その人が何に悩んでいるか」を具体的に思い浮かべます。

    02

    手元の素材で「実物」を見せられるか？

    今から自分で撮れる映像、実際に試した結果、ご自身の経験など、「手元にある材料」から逆算して企画を決めます。

    03

    なぜ「この1行目」と「この順番」にしたのか？

    複数の案を並べて比較し、「なぜこちらを選んだのか」の理由を言葉にして残しておきます。次回以降の改善がぐっと楽になります。

    よくある質問

    リールの台本を一度も書いたことがない初心者ですが、使えますか？+

    はい、まったく問題ありません。最初は「誰に届けたいか」と「手元で見せられる素材（または経験）」を一言ずつ書くだけで十分です。構成の組み立て方は、AIとやりとりしながら自然と身につきます。

    6つの形式は、1本につき必ず1つだけに絞る必要がありますか？+

    いいえ、複数を組み合わせても構いません。たとえば「ランキング」や「比較」は話の組み立て方の型であり、「アフレコ」や「トーク」は声や映像の見せ方の型です。「VLOGの映像にアフレコで声を重ねる」「比較の構成をカメラに向かってトーク形式で話す」といった応用も自在にできます。

    普段使っているスマホやPCの ChatGPT・Claude でも使えますか？+

    はい、そのまま使えます。手順2でコピーした手順書を新しいチャットに貼り付けるだけでスタートできます（動画ファイル自体の自動編集・書き出し機能のみ、Mac の Claude Code または Codex 専用となります）。なお、文字数上限やファイル添付の可否はご契約のプランによって異なります。

    このWebページ自体の中で、AIが文章や動画を作ってくれるのですか？+

    このページで行うのは、「完成作例の比較」「AIに渡す手順書や依頼文の自動作成・コピー」「zipファイルのダウンロード」までです。実際の文章生成や動画の書き出しは、コピーした指示文をご自身の ChatGPT・Claude・Claude Code・Codex に貼り付けて行います（※ページ内のサンプル原稿や数値は手順を説明するための作例であり、リールの完成動画のみ実際の撮影素材から書き出した実物です）。
