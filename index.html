01　はじめる

3つの手順で、1本目をつくる

押して、コピーして、貼る。作業はほぼそれだけです。迷ったら、上から順に進めてください。

言葉が分からないときは、ここを開く
手順書（スキル）

コピー・ペースト（貼る）
スマホは文字の入力欄を長押し →「ペースト」。パソコンは command（Windows は Ctrl）＋V。

ターミナル
Mac に文字で指示を出す画面。Claude Code・Codex の人だけ使います。打ち間違えても壊れません。
zip

自分の動画の型

いま外注している動画の作りを、AIで再現する

見本の動画を1本だけ AI に深く測ってもらい、同じ撮影素材からその1本を作り直します。見本と並べて差を見つけ、型（my-style.md）を直して作り直す、をくり返すと、テロップの字体・色・位置、カットの速さ、BGM、冒頭・締め・PR区間まで、あなたの型になります。仕上がったら、次からは素材と一言だけです。

1本を測る同じ素材で再現比べて型を直すくり返す新しい素材で使う

必要なものMac の Claude Code か Codex（上の「はじめる」で A・B・C を済ませた状態）／型にしたい代表の動画1本と、その撮影素材（編集前の映像・声。外注先に渡したもの）

    見本1本と、その撮影素材を入れる

    見本は、外注先から納品された元のファイルがあればそれを。Instagram から保存したものは画質が落ちます。下の1行をターミナルに貼ると「見本」と「素材」の2つのフォルダができて開きます。見本に完成動画1本、素材にその撮影素材を入れます。

    ✅ うまくいった印：「見本」「素材」の2つのフォルダが見える。

    撮影素材がない場合も始められますが、同じ動画を作り直してコマ単位で比べることはできず、新しい素材で見た目を比べる進め方になります（AI がそう伝えます）。

  2. 2

    1本を深く測って、型の初版を作る

    Claude Code か Codex を起動して（cd ~/insta-ai && claude または cd ~/insta-ai && codex）、これを貼ります。テロップの出る秒・位置・大きさ・色、カットの秒、音の大きさ、冒頭・締め・PR区間を測り、静止画と一緒に見せてから my-style.md を書きます。

    ① 測って、型の初版を作る

    ✅ うまくいった印：測った値の表と静止画が出て、最後に my-style.md を書いたと返ってくる。

    フォント名は「候補（推定）」として出ます。いちばん確実なのは外注先に「テロップのフォント名と太さ」を聞くこと。動画に使ってよいか（ライセンス）を確かめてから、公式の配布元・販売元で入手し、Mac の「Font Book」に入れます。

    同じ素材から、見本と同じ1本を作り直す

    ② 再現して、見本と比べる

  4. 4

    差を1つずつ直して、型に書き戻す（くり返す）

    これを何度でも貼ります。毎回、動画ではなく型（my-style.md）を直してから作り直すので、直したことが次の動画にも残ります。直した内容は型の「変更の記録」に1行ずつ残ります。

    ③ 差を1つ直して、型に書き戻す

    毎回くらべるもの・「同じ」にするコツ

    比べる順番は毎回同じです：①同じ秒の静止画の並べ比べ（冒頭・カット直後・テロップの出入り・PR区間・締め）②テロップの位置・大きさ・色・字数・出る秒 ③カットの秒 ④音の大きさ ⑤コマごとの差の数値。

    1回に直すのは1〜2個まで。テロップの字体・大きさ・位置のような目立つ差から片づけると、早く近づきます。数値はカットごとに分けて見てもらいましょう。大きくずれている区間が1つあると、ほかが良くなっても全体の数値はほとんど動きません。AI は「同じになった」とは言い切らず、残る差を数値と画像で見せます。

    気にならなくなったら、型を仕上げる

    並べて見て違いが気にならなくなったら、これを貼ります。残っている差は「許容」として型に書かれ、一区切りです。

うまくいかないとき

フォントが入ったのに、違う字体で書き出される。Mac を再起動するか、AI に「Font Book に入れた〇〇のファイルの場所を探して、それを指定して」と頼みます。

ffmpeg がないと言われる。「ffmpeg を Homebrew で入れて」と頼めば入れてくれます（途中で Mac のパスワードを聞かれることがあります）。

何度直しても数値が下がらない。見本だけズームや切り抜きをしている区間がないか、並べた静止画で見てみてください。カットの寄り・引きは数値に大きく効きます。

撮影素材が手元にない。外注先に「編集前の素材」を送ってもらえるか聞くのが先です。なければ新しく撮った素材で作り、見た目だけを比べます。

守ること（著作権・フォント・契約）

見本に使うのは、自分が投稿した自分の動画だけです。外注先の専用テンプレートや購入素材は、外注先との契約で扱いが決まっていることがあるので確認してください。BGM は見本から抜き出さず、自分で正規に入手した音源を使います。フォントのライセンスは自分で確認します（AI は「使ってよい」と判断しません）。

全部入りパック（zip）の video-edit/howto_mystyle.md（作り方）と prompt_mystyle.md（この指示文）にも同じ内容があります。スキル本体の決まりは references/my-style.md です。

02　AIが作った作例

人が編集した見本と、AIの再現

形式を押すと、見本とAIの再現が並びます。自分の投稿に近そうなものを選んで、「作り方」を開いてみてください。差の数字は、0に近いほど見本に近いという意味です。

判定の見方

「見本と同等」は数値の比較で基準内だったもの、「講師の確認済み」は講師が見て確認したもの、「改善を続けている作例（数値は見本との差）」は、見本との差が残る場面を数値で確かめながら直している作例です（AIの失敗例ではありません）。再現は撮影原本から作り、見本の映像・音は使っていません。

    使えます。アプリでは、コピーした手順書を新しい会話に貼れば始められます。動画まで作れるのは、Claude CodeとCodexです。登録方法や使える機能は、サービスやプランによって異なります。
