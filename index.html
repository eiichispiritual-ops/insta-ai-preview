Instagram のリールを作るツール

リールの台本と編集を、AIで作る。

手順書と「最初のひと言」を ChatGPT か Claude に貼ると、リールの台本が出ます。Mac なら撮った素材から、テロップ・カット・BGM まで入れて書き出します。

  • リール台本6形式の台本と撮影メモ。アプリでも使えます
  • リール編集撮った素材からテロップ・カット・BGMまで（Mac）

ほかにも：フィード投稿・ストーリー・プロフィールの原稿も作れます

  • 6形式リールの型
  • 36本手順書の資料

※リールの型はアフレコ・VLOG・トーク・抽象マーケ・ランキング・比較。資料数は zip に入っている参照資料の数。

どれで作りますか

スマホ・iPad・WindowsChatGPT・Claude のアプリに貼って、台本まで作ります。Mac で動画まで作りたいMac の Claude Code で、台本から動画の書き出しまで。Mac で Codex を使っているMac の Codex で、台本から動画の書き出しまで。外注の動画と同じ作りにしたい見本1本と撮影素材から、テロップ・カット・BGMの型を作ります（Mac）。

用語の説明

形式

Mac に文字で命令する画面。Claude Code と Codex で使います。打ち間違えても Mac が壊れることはありません。
zip
複数のファイルを1つにまとめたもの。ダブルクリックすると中身が出てきます。

    AIを選ぶ

    スマホ・iPad・Windows なら「ChatGPT・Claude のアプリ」

    それぞれの違い

    迷ったらアプリから始めてください。あとで Claude Code や Codex に移っても、作ったものはそのまま使えます。

    ChatGPT・Claude のアプリ：いつもの会話画面に貼るだけ。台本やプロフィールなど、文章を作ります。
    Claude Code／Codex：Mac のターミナルで動かします。台本に加えて、素材から動画を書き出せます。

    手順書をAIに渡す

    コピーされるのは手順書の文章だけです。あなたのファイルやアカウントの情報は含まれません。

    何を作りますか

    動画の書き出しは Claude Code か Codex でしか動きません。使う場合は手順1で選び直してください。

    最初のひと言を貼る

AIから質問が来たら

質問にはまとめて答えてかまいません。下の文をコピーして、（ ）の中を書き換えて送ってください。台本の「要確認」は、自分の実際の話に差し替えます。

直したいとき

一度に1か所ずつ頼むと、狙いどおりに直りやすくなります。

動画も作る場合

選んだ形式の作り方をコピーして、同じ会話に貼ります。

アプリの場合、AIが出すのは編集の段取り表までです。それを見ながら CapCut などで並べてください。書き出しまで自動で進むのは Claude Code と Codex です。

外注している動画を、AIで同じ作りにする

テロップ入れ・カット・BGM といった定型の編集を、外注に出さずに自分の Mac で回すための手順です。外注先から納品された動画を1本選び、テロップの字体や位置、カットの間、BGM、冒頭と締め、PR部分まで AI に測らせます。同じ撮影素材から作り直して見本と並べ、ずれを型（my-style.md）に書き戻す。これを差が気にならなくなるまで続けます。型ができれば、次からは素材を渡して一言頼むだけです。

外注費と比べるとき型ができたあとは、外注していた編集を自分の Mac で回せます。比べるのは「1本あたりの外注費 × 月の本数」と、型づくりにかかる最初の手間（見本1本を測って、作り直して、比べるのを数回）です。字幕やテロップの細かい調整は、型ができてからも自分の目で確かめます。

必要なものMac の Claude Code か Codex（上の「はじめる」で A・B・C を済ませた状態）／型にしたい代表の動画1本と、その撮影素材（編集前の映像・声。外注先に渡したもの）

    見本を測って、型の初版を作る

    Claude Code か Codex を起動して（cd ~/insta-ai && claude または cd ~/insta-ai && codex）、下の指示文を貼ります。AIはテロップが出る秒、位置、大きさ、色、カットの秒、音量、冒頭と締めとPR部分を測り、静止画で見せてから my-style.md を書きます。

    ① 測って型の初版を作る

    測った値の表と静止画が出て、最後に「my-style.md を書いた」と返ってくれば成功です。

    フォント名はAIの推定です。外注先に「テロップのフォント名と太さ」を聞くのがいちばん確実です。商用の動画に使えるライセンスか確かめてから、公式の配布元で入手して Mac の Font Book に入れてください。

  3. 3

    同じ素材で作り直す

    先に「何秒に何を出すか」の表が出ます。問題なければ「表でOKです。書き出してください。」と返してください。書き出しが終わると、見本と並べた比較画像と、ずれの大きいところが3つ届きます。

    ② 作り直して見本と比べる

  4. 4

    ずれを直して型に書き戻す

    この指示文は何度貼ってもかまいません。AIは動画ではなく型（my-style.md）を直してから書き出し直すので、直した内容は次の動画にも引き継がれます。変更は型の「変更の記録」に残ります。

    ③ ずれを直して型に書き戻す

    比べるところと、近づけるコツ

    毎回この順で見ます。
    1. 同じ秒の静止画（冒頭、カット直後、テロップの出入り、PR部分、締め）
    2. テロップの位置、大きさ、色、字数、出る秒
    3. カットの秒
    4. 音量
    5. コマごとの差の数値

    1回に直すのは1〜2か所にしてください。字体や大きさ、位置のように目立つずれから直すと早く近づきます。数値はカットごとに見ます。動画全体の数値だと、1か所の大きなずれに埋もれてほかの改善が見えなくなるためです。AIは「同じになった」とは判断せず、残っている差を数値と画像で出します。

  5. 5

    型を仕上げる

    並べて見て違いが気にならなくなったら、これを貼ります。残った差は「許容」として型に記録され、型づくりは終わりです。

    ④ 型を仕上げる

  6. 6

    新しい素材で作る

    素材の場所を書き換えて貼ります。my-style フォルダは消さないでください。別の回の見本があれば、その回にも型が合うか試せます。

    ⑤ 新しい素材で作る

    ⑥ 次回からの一言

うまくいかないとき

フォントが入ったのに、違う字体で書き出される。Mac を再起動するか、AI に「Font Book に入れた〇〇のファイルの場所を探して、それを指定して」と頼みます。

ffmpeg がないと言われる。「ffmpeg を Homebrew で入れて」と頼めば入れてくれます（途中で Mac のパスワードを聞かれることがあります）。

何度直しても数値が下がらない。見本だけズームや切り抜きをしている区間がないか、並べた静止画で見てみてください。カットの寄り・引きは数値に大きく効きます。

撮影素材が手元にない。外注先に「編集前の素材」を送ってもらえるか聞くのが先です。なければ新しく撮った素材で作り、見た目だけを比べます。

著作権・フォント・契約について

見本にするのは、自分のアカウントで投稿した自分の動画に限ります。外注先のテンプレートや購入素材は契約で使い方が決まっていることがあるので、先に確認してください。BGM は見本から抜き出さず、正規に入手した音源を使います。フォントのライセンスもご自身で確認してください。

同じ内容は、全部入りパック（zip）の video-edit/howto_mystyle.md と prompt_mystyle.md にも入っています。手順書の決まりは references/my-style.md です。

作例

いま載せているのは、アフレコ2本・抽象マーケ2本・ランキング・比較の計6本です。選ぶと、人が編集した見本と、AIが同じ素材から作り直した動画が並びます。差の数値は0に近いほど見本に近い、という意味です。

判定ラベルについて

「見本と同等」：数値の比較で基準内に収まったもの。

「改善を続けている作例」：ずれの残る場面を数値で確かめながら直している途中のもの。
再現はすべて撮影原本から作っていて、見本の映像や音は使っていません。

フィード投稿

リールで話したテーマは、そのままフィード投稿に回せます。表紙、困る場面、具体例、考え方、完成例を1枚ずつに分けると、読む人が自分のペースでめくれます。

  • 出てくるもの：ページごとの原稿と配置メモ
  • 用意するもの：見る人と、伝えたい工夫ひとつ

ストーリー

    よくある質問

    台本を書いたことがないのですが+

    最初は「誰に見せたいか」と「自分が見せられるもの」を書き出すところからで十分です。形式は作りながら覚えていけます。

    形式は1つに絞るものですか+

    組み合わせてかまいません。ランキングや比較は話の組み立て方で、アフレコは人物紹介や経験から本題に入る型です。VLOGにあとから声を入れる、比較をトークで話す、といった使い方もします。

    いつもの ChatGPT や Claude でも使えますか+
